# Creative & Brainstorming Prompts (10)

## 1. Brainstorming Partner
Help me brainstorm ideas for [PROJECT/TOPIC].
Generate [NUMBER] ideas. Mix of conservative and wild. For each: brief description.

## 2. Name Generator
Generate [NUMBER] name ideas for [PRODUCT/BRAND/PROJECT].
Style: [DESCRIBE STYLE - modern, playful, professional, etc.].
For each: name + why it works + available domain check suggestion.

## 3. Story Starter
Write a story starter about [PREMISE/THEME].
[WORD COUNT] words. [TONE] tone. End with a cliffhanger.

## 4. Character Creator
Create a character profile for a [GENRE] story.
Name. Age. Appearance. Personality. Backstory. Motivation. Conflict. Arc.

## 5. World Builder
Help me build a world for a [GENRE] story/game.
Geography. Culture. Politics. Economy. Technology level. Magic/supernatural rules.

## 6. Marketing Slogan
Generate [NUMBER] marketing slogans for [PRODUCT/BRAND].
Short. Memorable. Communicates [KEY MESSAGE].

## 7. Metaphor Generator
Generate metaphors for [CONCEPT/IDEA].
[NUMBER] metaphors. Each: the metaphor + what it illustrates + why it works.

## 8. Dialogue Writer
Write a dialogue between [CHARACTER A] and [CHARACTER B] about [TOPIC].
[STYLE - realistic, funny, dramatic, etc.]. [LENGTH].

## 9. Poetry Prompt
Write a [FORM - poem, haiku, limerick, etc.] about [TOPIC/SUBJECT].
[TONE]. [LENGTH/STRUCTURE constraints].

## 10. Creative Brief
Create a creative brief for [PROJECT].
Background. Objective. Target audience. Key message. Tone. Deliverables. Timeline. Budget.
