# Content Writing Prompts (10)

## 1. Blog Post Generator
Write a [WORD COUNT] blog post about [TOPIC] for [AUDIENCE].
Hook + 3 subheadings + bullets + CTA. Tone: [TONE].

## 2. Social Media Post
Write a [PLATFORM] post about [TOPIC]. 
[PLATFORM] best practices. [TONE] tone. Include hashtag suggestions.

## 3. Email Newsletter
Write a [LENGTH] email newsletter about [TOPIC] for [LIST NAME].
Subject line options (5). Opening hook. 3 main sections. CTA.

## 4. Landing Page Copy
Write landing page copy for [PRODUCT/SERVICE].
Headline (5 options). Subheadline. Problem agitate. Solution. Features. CTA.

## 5. Product Description
Write a product description for [PRODUCT] priced at [PRICE].
Benefits-focused. [LENGTH]. Include: headline, key benefits (bullets), use cases.

## 6. Video Script
Write a [LENGTH] video script about [TOPIC] for [PLATFORM].
Hook (first 5 seconds). Main content. CTA. [TONE] tone.

## 7. Case Study
Write a case study about [COMPANY/PROJECT] achieving [RESULT].
Problem → Solution → Results format. Include quotes and metrics.

## 8. Press Release
Write a press release announcing [NEWS] for [COMPANY].
AP style. Headline. Dateline. Body. Boilerplate. Media contact.

## 9. LinkedIn Post
Write a LinkedIn post about [TOPIC].
Hook. Personal insight. Value. CTA. 3-5 relevant hashtags.

## 10. Twitter Thread
Write a [NUMBER]-tweet thread about [TOPIC].
Tweet 1: Hook. Tweets 2-N: Value. Final tweet: CTA.
