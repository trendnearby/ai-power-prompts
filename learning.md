# Learning & Research Prompts (10)

## 1. Topic Explainer
Explain [TOPIC] like I'm [LEVEL].
Start with the basics. Use analogies. Include examples. Avoid jargon or explain it.

## 2. Study Guide
Create a study guide for [TOPIC/SUBJECT].
Key concepts. Important terms with definitions. Practice questions. Further resources.

## 3. Book Summary
Summarize the key ideas from [BOOK TITLE] by [AUTHOR].
Main thesis. Key concepts (with page references if possible). Actionable takeaways.

## 4. Research Assistant
Help me research [TOPIC].
Key questions to explore. Important sources to check. Current state of knowledge. Controversies.

## 5. Comparison
Compare [OPTION A] vs [OPTION B] for [USE CASE].
Criteria: [CRITERIA]. Pros and cons of each. Recommendation with reasoning.

## 6. Flashcards
Create flashcards for learning [TOPIC].
Format: Question on front, answer on back. [NUMBER] cards covering key concepts.

## 7. Practice Problems
Generate [NUMBER] practice problems for [TOPIC/SUBJECT].
Varying difficulty. Include solutions and explanations.

## 8. Concept Map
Describe how these concepts relate to each other: [CONCEPT 1], [CONCEPT 2], [CONCEPT 3].
Show the relationships and dependencies.

## 9. Timeline Creator
Create a learning timeline for mastering [SKILL/TOPIC] in [TIMEFRAME].
Weekly milestones. Resources for each stage. Practice activities.

## 10. Debate Prep
Help me prepare for a debate on [TOPIC].
Arguments for my position. Arguments against (and rebuttals). Key evidence. Common fallacies to watch for.
